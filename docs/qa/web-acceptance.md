## Ручная браузерная проверка

Проверено на production build через локальный backend:

- каталог загрузился, пример заполнил bbox/даты;
- кнопка «Рассчитать» записала applied query в URL;
- карта, справка и зоны показали один `result_id`;
- присутствуют AOI, два hotspots, три различимых класса, легенда и управление слоями;
- таблица содержит total и все три степени; origin `synthetic_demo` и ограничение видны;
- после изменения чернового west с 99.03 на 99.04 старые карта/справка остались привязаны к прежнему `result_id`, появилось предупреждение;
- кнопки GeoJSON/CSV/JSON доступны; их серверные ответы отдельно прошли round-trip-тесты;
- все три кнопки экспорта повторно вызваны из production frontend: backend получил GeoJSON, CSV и JSON запросы с тем же `expected_result_id` и ответил `200`;
- popup термоточки и зоны открываются на карте и закрываются клавишей Escape; найденная при повторной проверке техническая подпись `moderate` заменена на «Средняя степень поражения» и проверена в пересобранном frontend;
- интерфейс визуально проверен в тёмной и светлой темах, на обычном desktop viewport и 390×844;
- ключевые поля и действия доступны как label/role, диалог/tooltip закрывается Escape на карте;
- Swagger UI `/docs` открыл OAS 3.1 и показал каталог, readiness, анализ, contours и report со схемами и примерами.

Внешняя подложка считается независимой: при её ошибке UI показывает предупреждение, серверный результат, справка и экспорт не зависят от тайлов.

## Незакрытые условия WEB-002/011/012

Финальная конкурсная приёмка намеренно не отмечена как завершённая, потому что в workspace не передан разрешённый геопривязанный результат модели с реальными scene IDs, лицензией и независимо ожидаемыми площадями. Нельзя переименовать встроенный fixture в `model_output`.

До защиты нужно:

1. Подключить immutable manifest с origin `model_output` и передать набор допустимым способом.
2. Зафиксировать его checksums, processing/weights version, scene IDs, coverage/nodata и независимые ожидаемые площади.
3. Запустить Compose в чистом каталоге другим человеком; проверить restart и постоянный read-only mount.
4. Повторить браузерный сценарий, cURL/Swagger и файлы по одному реальному `result_id`; открыть GeoJSON в независимой ГИС.
5. Дописать сюда фактические commit/dataset версии, времена и вердикт. Только после этого WEB-002 и WEB-012 могут получить статус DONE по критериям плана.
