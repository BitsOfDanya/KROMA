# Каталог данных KROMA

Статус на 18 сентября 2026 года. `Получено` означает локальный, исключённый из Git файл; остальные строки описывают проверенный путь доступа, а не интеграцию. Исходники, версии, точные AOI и SHA-256 сохраняются в manifest. Данные для всей России загружаются пространственными и временными частями, а тяжёлые растры — только для выбранного региона или инцидента.

Официальная [ИСДМ-Рослесхоз / Авиалесоохрана](https://public.nffc.aviales.ru/main_pages/) важна для сопоставления происшествий, но открытый воспроизводимый API с verified incident labels пока не подтверждён. Полный интерфейс требует входа; правовой режим выгрузки проверять до использования.

Для актуализации границ рассмотрены [регулярные OSM extracts Geofabrik](https://download.geofabrik.de/russia.html) (свежие, но многогигабайтные и ODbL), [OpenData.Earth](https://open-data.earth/data/administrative-boundaries) (версия 2026, CC BY, но нужен запрос доступа и проверка исходных российских полигонов) и официальный [ОКАТО Росстата](https://www.rosstat.gov.ru/opendata/7708234640-okato) (коды/названия, без геометрии). Для соответствия субъект→федеральный округ есть [официальный перечень Росстата](https://www.rosstat.gov.ru/storage/mediabank/met_519-22092025.pdf); машинно проверенная таблица ещё не собрана. Любую замену слоя нужно сопоставить с идентификаторами и лицензией до публикации статистики.

## Существующие локальные данные

`research/experiments/build_evaluation_cohort.py` проверяет SHA-256 NASA CSV и вызывает **существующий** нормализатор `backend/app/services/firms.py`. `data/raw/firms/sample_viirs_snpp_071223.csv` и `data/interim/sample_viirs_snpp_071223.jsonl` находятся локально вне Git. [Manifest выборки](../../research/experiments/viirs-pilot-manifest.json) фиксирует 200 кандидатов без reference labels. Один день S-NPP не позволяет оценить Thermal Memory, сезонность, false-positive reduction или nationwide качество.
