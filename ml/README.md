# ML

Пакет `kroma_ml` предназначен для обработки тепловых аномалий, фильтрации ложных срабатываний, признаков, кластеризации событий, Thermal Memory, confidence, приоритизации, оценки гарей, прогнозирования и оценки качества. Пока это только границы модулей, без моделей и алгоритмов.

Исследовательские notebooks и гипотезы находятся в `research/`. Проверенный код переносится в `ml/src/kroma_ml/`.
