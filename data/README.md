# Данные

Данные хранятся локально и исключены из Git. Сохраняйте сведения об источнике, дате загрузки, лицензии и обработке в `research/external_sources/` или `docs/data/`, не добавляя сами большие файлы.

| Каталог | Содержимое |
| --- | --- |
| `raw/` | Исходные загрузки без изменений |
| `external/` | Сторонние справочники и дополнительные наборы |
| `interim/` | Промежуточные результаты обработки |
| `processed/` | Подготовленные к анализу данные |
| `samples/` | Локальные небольшие выборки |
