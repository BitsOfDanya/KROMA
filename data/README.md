# Данные

Данные хранятся локально и исключены из Git. Скрипты создают `raw/` для исходных загрузок, `interim/` для нормализованных наблюдений и `samples/` для исследовательской выборки. Остальные каталоги добавляйте по мере необходимости. Источники и условия использования фиксируйте в [документации](../docs/data/sources.md), не добавляя сами наборы данных в Git.
