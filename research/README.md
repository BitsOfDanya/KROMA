# Исследования

Здесь хранятся обзор источников, литература, гипотезы, notebooks, эксперименты и отчёты. Фиксируйте входные данные и способ воспроизведения эксперимента. Не добавляйте исходные датасеты, секреты и тяжёлые артефакты в Git. Код, пригодный для продукта, переносите в `ml/src/kroma_ml/` или `geo/src/kroma_geo/`.

Первый воспроизводимый пилот оценки описан в [документе](../docs/research/evaluation.md). Его рецепт находится в `research/experiments/build_evaluation_cohort.py`; метки для кандидатов ещё не собраны.
